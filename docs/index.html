🚀 Installazione Rapida

Segui questi passaggi per avviare DocFilter in pochi minuti.

Clona il repository

git clone https://github.com/abeggi/docfilter.git
cd docfilter

Configura il backend

cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
mkdir -p data
deactivate

Build del frontend

cd ../frontend
npm install
npm run build

Avvia l'applicazione

chmod +x docfilter.sh
./docfilter.sh start

L'app sarà disponibile su http://localhost:8000
